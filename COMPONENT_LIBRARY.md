# Component Library

## Existentes
- `BallMachine3D`: bolillero con iluminación Code Coffee.
- `ZoneBoard`: fixture compacto de una zona.
- `TeamLine`: pareja, integrantes, seed y estado.
- `ZoneResultCard`: control de resultados por zona.
- `WorldBracket`: cuadro final tipo Mundial.
- `ChampionPodium`: ceremonia final.

## Componentes visuales base
- Botones `.primary` y `.secondary`.
- Paneles de configuración y fixture.
- Cards en estados neutral/active/winner/receiving.
- Etiquetas `eyebrow`, `live-pill`, `team-badge`.

## Reglas
- Props tipadas.
- No declarar colores inline.
- Estado interactivo perceptible por color, borde y forma; no solo por glow.
- Mantener nombres visibles mediante truncado controlado.
