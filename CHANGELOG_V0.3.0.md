# Changelog v0.3.0

- Responsive recalibrado para Full HD con zoom de navegador al 125 % — viewport efectivo 1536×864.
- Bolillero reducido y contenido de revelación convertido en una card compacta inferior.
- Sorteo visual por vueltas: se incorpora una pareja en cada zona antes de comenzar la vuelta siguiente.
- Animación individual al insertar cada pareja en su mesa.
- Cuadros de zona flexibles para cantidades de parejas que requieren múltiples rondas o pases libres.
- Semifinales y final con conectores SVG calculados desde la posición real de cada card.
- Scroll horizontal interno en brackets compactos, sin romper el viewport global.
- Tipografía general y títulos relevantes ampliados para proyección.
- Título y cinta de campeones reforzados.
- Sonidos funcionales mediante Web Audio API y control para activar/desactivar.
- Control real de pantalla completa con iconos expandir/contraer sincronizados.
- Importador Excel tolerante a variantes de encabezados.
- Descarga de plantilla Excel desde la pantalla inicial.
- Guía integrada y documentación de formato de carga.
- Reducción moderada de carga gráfica del bolillero 3D para mejorar estabilidad en televisores y notebooks.
